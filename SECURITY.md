# Security

`SECRET_KEY` generated by Remnawave Panel is a credential. Never paste it into
an issue, commit, CI variable, command-line argument, screenshot, or chat.

The installer reads it silently from `/dev/tty` and stores it only in
`/opt/remnanode/.env` with mode `0600`. The public repository contains no live
panel token, node secret, subscription URL, VPN credential, private key, private
infrastructure server IP or domain, or resource UUID.

To report a vulnerability, use a private GitHub security advisory for this
repository. Do not open a public issue containing live infrastructure data.
